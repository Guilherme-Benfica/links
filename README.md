# Links dos Simulados (AWS e Azure)

Página estilo Linktree com os links dos meus simulados de certificação na Udemy. HTML e CSS puros, sem dependências.

## Como personalizar

1. Abra `index.html` e troque `Seu Nome`, os links `SEU-LINK-...` pelos links reais dos cursos na Udemy e `SEU-PERFIL` pelo seu usuário do LinkedIn.
2. Coloque sua foto como `foto.jpg` na raiz (opcional).
3. Para adicionar um simulado, copie um bloco `<a class="link aws">` ou `<a class="link azure">` e edite.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie os arquivos.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O link será `https://SEU-USUARIO.github.io/NOME-DO-REPO/`. Use esse link no LinkedIn.
